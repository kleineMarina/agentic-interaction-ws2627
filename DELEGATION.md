# Delegation Boundary

Which actions the agent may carry out on its own (**alone**) and which need my approval first (**approval**: the agent asks and acts only after a yes).

| # | Action | Decision | Justification |
|---|---|---|---|
| 1 | Read the appointments of a day | alone | The calendar the agent uses contains work and study appointments that it needs for almost every task, and reading it changes nothing. A private calendar with personal appointments would need approval, like the notes. |
| 2 | Look up the weather | alone | Only reads data and contains no sensitive information. |
| 3 | Search train connections | alone | Only reads data and contains no sensitive information. |
| 4 | Read notes | approval | Only reads data, but notes may contain sensitive or private information. |
| 5 | Create a personal block in the calendar (e.g. travel time, no other attendees) | alone | Only affects me and is easy to undo. The agent must report it afterwards so I know what to undo if needed. |
| 6 | Reschedule an appointment with other attendees | approval | Affects other people: they would have to adjust their plans, and the change can't be quietly undone. |
| 7 | Book a train ticket | approval | Costs money and can't easily be undone. |
| 8 | Send a message to third parties | approval | Goes to other people and can't be taken back once it has been read. |
| 9 | Create a note | alone | Only affects me and is easy to undo. The agent must report it afterwards so I know what to undo if needed. |
| 10 | Delete a note | approval | The note is gone for good. |

## My rule

The agent may act alone when it only reads non-sensitive information or when an action affects only me and is easy to undo, and it always reports what it did; anything else needs my approval.

## Observations from the role play

1. **Booking the train (cards B and C):** The agent searched connections without asking, which felt right, and asked before booking, which was also right. But when it asked, I was missing information to decide: whether a discount applies to the ticket and which account it would book with. An approval question is only useful if it contains everything needed to say yes or no.
2. **Tidying up the notes (card F):** The agent asked before deleting old notes, but it never asked what "tidy up" means. Approval at the end does not replace a clarifying question at the start when the request itself is unclear.
3. **Message to the stand-up (card E):** The agent first wrote the message as a note, without asking, so I could see the exact text before anything was sent. Then it asked whether to send it. This worked well: creating the note was harmless because it can easily be deleted, and seeing the draft let me approve the actual content and not just the idea of sending a message.
